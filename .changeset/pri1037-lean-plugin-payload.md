Fix the OpenClaw PD plugin payload so a real `agent exec` round no longer times out at workspace-plugin publication. The shipped plugin component is now the self-contained `dist/bundle.js` plus its single native dependency (`better-sqlite3`): the historical `file:./core` rewrite and the inlined-dependency list are gone from `plugin/package.json`, so an install carries 322 files / 33 MB instead of 16,425 files / 126 MB (and OpenClaw's per-round plugin-source capture drops from ~19,167 files / 153 MB per build to 321 files / 33 MB). Also: the bootstrap executor is now delivered from the payload's own `release-manager` component instead of the executing package — during an update the executor used to re-deploy its own stale code, so `installs.json` regenerated by pre-PRI-1021 code could never converge; `release-locks/plugin` is regenerated for the lean manifest, and the plugin package's own manifest no longer lists `@principles/core` as a runtime dependency (it is bundled at build time). PRI-1037 S9.

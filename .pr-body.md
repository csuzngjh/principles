## Summary

PD Console WebUI UX/UI overhaul covering accessibility, component standards, i18n, and reduced-motion support.

## Changes

### P0 - Accessibility Fixes
- Semantic interactive elements: all div onClick now have role=button, tabIndex, onKeyDown for keyboard support
- aria-label on icon buttons (bookmark, checkbox, theme toggle)
- aria-hidden on decorative icons (sidebar, refresh buttons)
- Skip link added for keyboard navigation
- All native input/select replaced with shadcn Input/Select + labels

### P1 - Component Standards
- shadcn init: created components.json, added 7 components (Input, Select, Dialog, AlertDialog, Sheet, Tooltip, Sonner)
- AlertDialog confirmation for destructive actions (delete workspace, reject sample)
- Sheet replaces custom AgentDrawer (focus trap, ESC close, aria-modal)

### P2 - UX Improvements
- i18n consistency: +67 keys, eliminated hardcoded text, dates use Intl.DateTimeFormat
- URL state sync: filter/pagination state synced to URL query params on 4 pages
- Spacing: space-y-* replaced with flex gap-* per shadcn rules (12 files)
- Colors: hardcoded colors replaced with semantic tokens (5 files)
- Reduced-motion: global CSS rule + motion-reduce: Tailwind variants (6 files)

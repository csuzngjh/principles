## Summary

Add backend APIs for the Console Control Center without exposing raw
config files or secrets.

**4 API endpoints:**

| Method | Path | Function |
|--------|------|----------|
| GET | `/api/v1/config/summary` | Redacted config summary |
| GET | `/api/v1/config/catalog` | Available runtime/model catalog |
| PATCH | `/api/v1/config/agents/:name/binding` | Update agent runtime binding |
| GET | `/api/v1/config/readiness/:name` | Readiness test |

**Security guarantees:**
- Never returns raw provider objects, tokens, API keys, or env values
- Validates before write, rejects malformed existing config
- Rejects payloads containing secret-like fields (`apiKey`, `token`, `secret`, etc.)
- Atomic YAML writes (tmp → rename)

**Readiness states:** `ready`, `needs_setup`, `not_ready`, `disabled`, `unknown`
with structured reason + nextAction.

关键点（详见设计文档）：
1. **shared route 必要条件化**：PRI-1137 后 shared 是唯一普通装配入口；host-runtime `ActivePrinciplePromptResult` 增加逐原则冻结字段（PD 自有接口，仓内变更）——两条入口的生产者/消费者明确；不事后读库、不反向解析、版本 unknown 不制造、**不依赖官方会丢弃的 injectedExpectations hook-result 字段**（登记走 PD 内存注册表），旧上游字段不得成为 Path A 生效条件。

3. **最小检查器**：单字符串包含检查；三值；空体/截断/超限/失败处理；输入/期望/事件/登记全有界；边界常量 `post_assembly_system_prompt_via_llm_input`；不判 D/confirmed/timely。
4. **权限/回滚**：生产 `allowConversationAccess` **已授权**（只读核查）；零配置变更；未授权→`presence_source_unavailable` 诊断事件（不静默、不解释为"未注入"）；回滚恢复运行前配置值、不一律删除；不宣称"无副作用"。

## 3. 三项修订约束的落点核对

1. **候选历史不完整→无唯一关联**：historyComplete 粘性（TTL/淘汰/重登记均不洗白）；solo 存活者/重登记快照 → `history_incomplete`。✔
2. **无 all_candidates_agree**：多活快照一律 `unknown:ambiguous_binding`；禁止清单（取最新/FIFO/时间接近/编号冒充宿主/正文合并）全部未采用。✔
3. **登记表全局有界**：键/快照/字节/TTL/单次检查+事件输出全部集中常量并实测；超限/过期/淘汰可观察（stats+事件字段）并影响关联资格；lossyKeys 为有界标记集而非 tombstone 表。✔

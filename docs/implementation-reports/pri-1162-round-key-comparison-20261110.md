# PRI-1162 一轮同输入比较 — FIFO vs 共享装配轮次键（2026-11-10）

机器可读版本：`pri-1162-round-key-comparison-20261110.json`（逐轮原始记录含 oversized/dropped 分类）。执行脚本（入库）：`scripts/dev/aa-selector/pri1162-round-key-comparison.mjs`。

## 冻结输入（卡 v0.1 §5，先于读结果冻结）

- 候选集：WAL-0 一致性快照副本（state.db sha256 `830fbd24…`），**18 条** prompt 候选，base 序 = activated_at ASC；与 PRI-1160/PRI-1161 证据同源。
- 预算：**4000**（主口径）/ **2500**（辅口径）。
- 轮次推进：roundKey = k+1（写入本轮后读 `MAX(turn_index)+1` 的持久化语义），k = 1..18（N=18 全领先周期）。
- FIFO 臂：roundKey 缺失（已安装生产/降级调用语义；即合并 #2455 后的 Native FIFO 基线）。
- 单位：字符（无可靠 tokenizer，不报 Token）。

## 结果

| 指标 | FIFO（12 轮） | 轮转（12 轮窗口） | 轮转（18 连续轮） |
|---|---|---|---|
| 4000 入选候选 | 10/18（8 条 0 次） | **17/18** | **18/18（全覆盖）** |
| 4000 字符/轮 | 恒 3727（逐轮字节一致） | 3975–4000 | 3855–4000（合计 71,195） |
| 2500 入选候选 | 6/18（12 条 0 次） | 17/18 | **18/18** |
| 每条入选次数 | 12 或 0 | 1–9 | 6–15 |
| 最长未入选间隔 | 饿死条 = 全程 12 | — | 1–12（首尾环形窗口效应） |

- **通过线（冻结口径）全过**：12 轮窗口 17 ≥ max(FIFO+4, 14)=14 ✅；每个 FIFO 饿死候选在 18 连续轮内至少入选一次 ✅；roundKey 缺失时 FIFO 输出逐轮字节一致（回滚安全）✅。
- **oversized 单列（验收说明 2）**：本快照在两个预算下 oversized = **0 条**（最大块 1219 < 2500）；逐轮原始 oversized/dropped 分类完整保留在报告 JSON，若有此类候选将按原始失败结果单列、不计入覆盖数学。
- **额外开销**：轮转 2.95ms/轮 vs FIFO 3.14ms/轮（同量级，无增益损失）；字符层面轮转装填更满（预算利用率更高），但每次注入仍严格 ≤ 预算。

## 结论（按验收说明 4 分层）

- **仓库共享入口已验证**：#2398 接线在真实生产链（注册入口 → shared runtime → `prepareOpenClawPromptRound` → `buildActivePrinciplePromptContext`）上按冻结输入修复单 Session FIFO 覆盖偏差：紧预算下从"恒前缀 10/18、8 条永久饿死"变为"18 连续轮 18/18 全覆盖"，同轮重试字节稳定，非用户轮/缺键回 FIFO。结论限定：单 Session 持续推进条件；跨宿主/跨 Session 归 PRI-930。
- **发布版本尚待验证**：已安装 3.1.3 的运行时入口疑似发布物与源码不一致（独立待核查项，证据与判定方式见实施卡 §3）。装上含 #2398 的构建前，生产持续 FIFO；本票不改发布管线、不等待该核查。

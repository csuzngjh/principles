## 范围与调用链

1. 保持所有默认生产诊断生成/校验为 V1，保持 Owner 显式 binding、审批、shadow/live 权威不变。
2. 新增严格 V2 模型输出契约及纯只读结构/引用验证；结果明确不证明语义正确，不赋予后续生成权限。
3. 复用现有 artifact/candidate JSON 存储保存显式 V2 输入，验证来源局部ref的无损保存、幂等和重启恢复，不增加数据库表。
4. 连接系统拥有的实际输入来源摘要证据与来源引用（不宣称完整快照）；未证明当次canonical允许集合时，返回不可证明/空允许集合，不从诊断输出或当前Ledger倒推。来源不完整不启用canonical自动关联。
5. 隔离合成数据完成schema/引用负例、持久round-trip、重放和原V1回归；shadow结果不能写Owner binding或启动Scribe。

## 不执行

不切换默认V2生产prompt，不启用自动关联，不实现OD-04自动续接；不新增suppress/restore写入动作，不改已有工件/真实治理数据，不运行真实模型，不发布/安装。

## 验证与失败

版本/schema/上下文不匹配均显式失败；不得当作无关联成功。完整模型输出与系统envelope分别校验。真实持久测试使用临时合成数据库。任何环节未打通必须列为NOT VERIFIED，不以纯函数通过声称生产闭环。

新增契约和系统来源摘要证据为已授权的持久/公共契约变化；不新增服务、表、开关、依赖或调用。若实际输入集合需超出本设计的新数据生产来源，记录具体缺口，在对应关联保持不可用条件下完成独立安全部分。

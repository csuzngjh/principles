- **Occurrence**: PRI-1012 / pd-companion. The update chain flips the installed plugin's version marker before it lays the component directories (`installer.ts:3945 installPluginToStaging` vs `:3960 syncPdCli`). Companion's `watchInstalledVersion()` read that flip while the console was running, restarted after 1s and stat-ed `~/.pd/runtime/pd-cli/dist/index.js`. `isSafeExistingFile()` answered `false` for a file that was merely not written yet, and `spawnCli()` treated that as a deterministic defect: `onSpawnError` → `degraded(launch_failed)`, permanently, with no log line at all. Measured window on the 2.3.6 transaction: marker flip at 14:11:29.004Z, journal `staged` at 14:13:18.941Z — 1m50s of "missing" that means "still installing".
- **Impact**: a healthy install was reported to the Owner as damage. 24 audited `version_change_restart` events split 5 RESTARTED_OK / 13 SPAWNED_NO_START / 4 SILENT_NO_SPAWN / 2 QUIT_BEFORE_RETRY, and the degraded tray copy advised re-running `npx create-principles-disciple` — which over an existing install overwrites the current runtime with the bundled version (AGENTS.md §1.1). Because `watchInstalledVersion()` returns early unless the state is `running`, a degrade was never retried: recovery required a manual tray restart.
- **Fix**: `entry-verdict.ts entryFileVerdict()` separates "not on disk yet" (`transient: true` → bounded wait 2/5/10/20/40/60s) from "this value can never be spawned" (`transient: false` → immediate degrade). The wait gets its own counter and budget so the crash-loop ladder keeps its short horizon, and `pd_cli_entry_not_ready` logs entry / detail / state / willRetryInMs / waitsLeft / fromVersion / targetVersion so a race is distinguishable from damage after the fact. Guards: `tests/lib/entry-verdict.test.ts` (real filesystem, incl. staged-then-laid flip), `tests/lib/supervisor.test.ts` (ladder exhaustion, budget separation, reset paths), `tests/main/entry-wait-wiring.test.ts` (assembly; source characterisation because Electron `main.ts` cannot be driven inside vitest — precedent set by `coexistence.test.ts`).

installer 测试簇把 `workspaceDir` 写成 POSIX 字面量（`/tmp/pd-test-ws` 等 4 个文件）。win32 上 `install()` 入口的 `isUsableWorkspacePointer` 判定该形态不可用并抛错，23 个用例在触到被测行为（网关停止、事务 journal、payload 形态门）之前就死掉；同一批用例在 Linux CI 全绿，于是 Windows 覆盖静默缺失，CI 徽章完全看不出来。修法是 fixture 路径由本平台可用的受治 temp root（`os.tmpdir()`，`scripts/test/temp-lifecycle.mjs` 已在每个平台把 TMPDIR/TEMP/TMP 重定向到 run 级目录）派生，而不是假设 `/tmp/` 通用。

教训：断言「测试覆盖了 X」的前提是 fixture 输入真的能通过 X 之前的生产校验；跨平台可移植的 fixture 路径必须来自本平台 authority，且失败必须在该平台的本地验证里暴露——POSIX 路径字面量只在一台 Linux 上被证明过。

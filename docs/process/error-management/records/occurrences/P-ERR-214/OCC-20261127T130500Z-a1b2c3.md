Devin Review found that a pending Owner verdict override captured for an older Artificer input became unrecoverable after the upstream revision completed: the runner correctly refused to apply the stale evidence, but the refusal was a permanent `input_invalid`, while the same stale resolution remained the first recovery candidate on every retry. The evaluator therefore could neither enter the formal revision path nor be manually recovered into a fresh evaluation.

Fixed by making stale-input owner resolutions a bounded lifecycle state rather than a permanent runner failure. The leased evaluator proves whether the resolution's durable output still targets the current Artificer artifact; when it does not, the runner records the resolution as `superseded` through a diagnostic-json CAS constrained by the active lease owner and lease generation, emits `evaluator_owner_resolution_stale_input`, and then proceeds through the normal completion-intent/fresh-execution path. Regression coverage proves that the stale override is not applied, is durably superseded, and the evaluator evaluates the revised Artificer input instead of failing permanently.

新增 win32 无扩展名 Git Bash 垫片时，把安装目录路径插进 sh 脚本，却沿用相邻 POSIX 分支的不完整转义（只转义双引号）。Windows 路径本身就是反斜杠，且 `$`、反引号在双引号内仍会展开；单元测试按平台分支 gate、CI 跑 Linux，PR 评审也没看出来，最后由 CodeQL 分支扫描（high）拦下。修法：垫片渲染收敛到单一纯函数，目标路径改用 POSIX 单引号（`'\''` 闭-转-开惯用法），并在任意平台都能执行的正向/对抗路径测试里锁住字节与真实 sh 转发行为。

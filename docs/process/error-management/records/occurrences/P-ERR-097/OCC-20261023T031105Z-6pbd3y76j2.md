2026-10-23 PRI-1021: OpenClawHostInstaller.install() wrote a principles-disciple installRecord into the host's legacy ~/.openclaw/plugins/installs.json (writeInstallRecord, introduced via PR #1300). From OpenClaw 2026.10.5 the mere presence of that path is a hard refusal in the doctor state-migration chain (code unsupported-plugin-install-index) and the same file gates update admission; on the Owner's machine the agent DB stayed at schema v24 and the gateway crash-looped with exit 78 for hours until the file was retired by hand. Root cause is the same as ERR-097: PD treated a host-interpreted path as inert data. PR #1300 had hardened the merge semantics (preserve other plugins' records) without asking whether PD owned the file at all — a merge-safe write is still a boundary write. Fix deletes the writer and pins the boundary with a negative regression test (packages/create-principles-disciple/tests/openclaw-host-installer.test.ts).

- **What happened**: PR #2425 (PRI-1139 Group E) added `tests/integration/api-path-alias-equivalence.test.ts`, which imports `../../src/server/index.js` to drive the real request listener. That module ran `main()` unconditionally at module scope. Under vitest the import therefore started a second production console: `resolveWorkspaceDir()` picked the first ENABLED workspace from the developer's real console config, `initServices()` reconciled update history against the real `~/.pd`, `migrateLegacyExtensionBackups()` moved real `~/.openclaw/extensions` backup directories, and only then did `server.listen(3100)` run. On the reviewer's machine a console already owned :3100, so the worker died with an uncaught `EADDRINUSE` after all 42 tests had passed — the run exited 1. CI stayed green because the CI HOME has no registered workspace and :3100 is free.
- **Why it's wrong**: Same root cause class as ERR-133 — one file serving as both module and CLI with a top-level driver. A test import is an invisible execution path: nothing "runs" the console, yet the real start-up performed user-level filesystem mutations and port binding. A green CI run is not evidence of isolation when the side effect depends on machine state.
- **Correct approach**: Guard the start-up call with `isMainModuleEntry()` (realpathSync canonicalization; PRI-892 precedent) and move the packaged start into `src/server.ts`, whose build output `dist/server.js` is the installed entry — it now calls `main()` explicitly. Direct executions of `src/server/index.ts` (`npm run dev`, Playwright e2e, ai-user bootstrap) still start because `argv[1]` is the module.
- **How to prevent**: Before importing a module for its exports, check module scope for start-up calls (`process.argv` reads, `server.listen`, migrations, fs writes). A test that imports a production entry must first prove the import is side-effect free.
- **Regression guard**: `packages/pd-console/tests/integration/server-import-no-autostart.test.ts` spawns a child that only imports the module and must exit 0 printing `IMPORT_ONLY_OK`; pre-fix it hangs on the listening server or dies with EADDRINUSE. Verified in PR #2425 fix commit 9f3b361df: the equivalence suite now passes with a live console still holding :3100.

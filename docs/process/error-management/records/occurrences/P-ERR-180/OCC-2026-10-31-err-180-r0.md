The regression test added by the same PR asserted `toContain('codex_conversation_ingestion:')` / `toContain('enabled: true')`, both true of the flattened string — green suite, unusable output. Fixed by emitting a single-line flow mapping and asserting the snippet parses as exactly one flat key.

pd-hook declared fail-open but three terminal paths (unguarded write-out tail, async EPIPE 'error' event with no listener, unbelted entry rejection) could still exit 1 and block the host tool call; the guarantee was only ever checked at pipeline level, never from a spawned process. EPIPE is called out separately from the other stream faults: when the failed stream is stdout the JSON object itself cannot be delivered (exit status still fails open, output is best effort), while a failure confined to stderr leaves stdout fully deliverable and exactly assertable.

光标元素从决策面板迁移到批准按钮内部时，旧位置的元素未删除，两个元素共享同一 id。GSAP 目标选择器按 querySelectorAll 语义命中全部同 id 元素，同一补间驱动两份拷贝，各自停靠在旧/新位置——成片中表现为「两个原点」，其一压住按钮字面，被 Owner 预览评审发现。根因类：重构迁移 DOM 元素后残留旧实例 + 假定选择器只命中首个元素。防法：迁移即删（同一次编辑内完成搬与删）、提交前对组合文件做 id 查重、选择器行为可疑时先查 querySelectorAll 长度。

- **What happened**: A cross-package consumer suite (codex-adapter workspace-worker) was run green while the dependency package's `dist/` (host-runtime, changed in the same task) had not yet been rebuilt — the suite exercised the stale artifact and passed. After the dependency was rebuilt, the SAME suite failed on a fixture not migrated to the new contract. The task's first all-green claim was therefore false, and the canonical merge gate could not catch it because `verify:merge` does not run the adapter package suites (known gate blind spot, PRI-952 era).
- **Reproduction**: PR for PRI-995 (2026-10-16): codex-adapter suite passed at 19:54 against the bootstrap-era host-runtime dist; the independent review agent reran it after the dist rebuild and got 1 failure (`workspace-worker.test.ts:741` — artificer task without a scribe dependency now stopped by the new intent preflight).
- **Invariant**: A package-suite result is only valid for the source state its RESOLVED dependency artifacts were built from — rerun every downstream consumer suite after rebuilding any workspace dependency it resolves through `dist/`.
- **Fix/correctness**: The fixture was migrated and the suite re-verified against the rebuilt dist; the implementation report's false "all green" claim was corrected.
- **Guard**: Manual discipline (no mechanized guard yet): after `npm run build` in any workspace package, re-run the consumer packages' suites in the same change; treat a pre-rebuild green as provisional.

## 2. 研究必要性评估

**RQ6 当前证据状态**：Principle 是否优于高质量经验 Summary——三源一致指向「未观察到优势」：
1. CEB-002（同任务族、预注册探索性）：p=1.0，描述性 B 劣于 C（24/32 vs 28/32）；
2. CEB-001（同任务族）：NOT_EVALUABLE，无 B/C 分化证据；
3. PL 主线 C-A（另一任务族，三种子）：NOT_SUPPORTED（policy 无任何维度优于 summary）。

**继续投入的边际价值判断**：确证性 C 臂要产出可归因结论，必须先解决 CEB-003-P 暴露的载荷混杂（内容抽象 × 语言形式不可分离）——即需要「载荷匹配的强摘要」制作与核验，再叠加独立预注册与授权。该前置与 CEB-002 确证轮的设计决策（是否启动、何时、何种载荷匹配策略）是同一决策簇；在 PRI-1035 出题路径裁定（PR #2195 决策卡）与确证设计定案之前**单独启动 PRI-1039 会重复已知混杂问题并产生不可归因数据**。

**不建议永久关闭的理由**：RQ6 是 SPEC 正式研究问题；「B 特异性是否存在」（CEB-003-P 未解决后续问题之首）若在确证轮成立，C 臂价值将随之上升；现有探索性「无优势」结论的功效有限（CEB-002 功效分析在案），不足以关闭问题。

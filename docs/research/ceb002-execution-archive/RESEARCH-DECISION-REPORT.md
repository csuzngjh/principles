### 2. A=C "完全一致"的准确含义（**勘误**）

终局报告称"A=C 完全一致"**为汇总口径而非逐单元口径**。精确事实：

- **汇总计数一致**：A 臂 28 PASS/4 FAIL = C 臂 28 PASS/4 FAIL ✓
- **逐单元 NOT 完全一致**：28/32 单元逐单元匹配，**4 单元不一致**：
  - L1-03/r1: A=FAIL, C=PASS
  - L1-03/r2: A=PASS, C=FAIL
  - L2-07/r1: A=PASS, C=FAIL
  - L3-08/r2: A=FAIL, C=PASS

**结论**：A 与 C 在该题集上行为等效（无系统性差异——4 个不一致双向对半），但"完全一致"的表述过强，应更正为"汇总等效"。

### 3. B 臂失败模式（关键发现，非报告中已充分展开）

B 臂 8 个失败中有 **6 个为 VIOLATION_ABSTENTION_OBTAINABLE**（可获取但未获取必要信息即提交），且**三个 case 在两次重复中均一致失败**：
- L1-02: r1+r2 均 VIOLATION_ABSTENTION_OBTAINABLE
- L2-04: r1+r2 均 VIOLATION_ABSTENTION_OBTAINABLE
- L2-05: r1+r2 均 VIOLATION_ABSTENTION_OBTAINABLE

这**不是随机失败**——是原则注入导致的**系统性过度谨慎/不作为**（该获取的证据不获取即提交）。这与 A/C 臂的 no_report（忘记提交）是**不同的行为违规类型**。

### 4. 主分析复算（全部一致 ✓）

L2+L3 判别层 8 个 case 级配对：3 B-worse / 2 C-worse / 3 协同，精确 McNemar p=1.000000。逐 case 复核与冻结的 reduceCaseLevel 输出完全一致。

### 5. 数据完整性

无实质性不一致。唯一勘误为上述"A=C 完全一致"表述过强。所有账本、裁定、报告间的数字经交叉核对全部一致。

## 二、时间成本复盘

| 项目 | 值 |
|---|---|
| 预计墙钟 | 50–70 分钟 |
| 实际墙钟 | **~130 分钟**（超出 60–80 分钟） |
| 批次数 × 单元/批 | 12 × 8 = 96 |
| 平均批耗时 | ~11 分钟/批 |
| 每单元平均耗时 | ~1.4 分钟（3.1 requests/unit 平均） |

**差额原因（日志可证明）**：
1. **实际并发=1 而非 3**：runner 在每批内**串行**执行 8 个单元（CLI 单进程调用）。"并发 3"的设计目标在当前 CLI 接口下未实现——需要 3 个并行进程调用 runner 的不同子集，但这是研究运行器接口设计问题，不影响数据有效性。
2. **每单元平均 3.1 请求 × ~25s/请求** ≈ 78s/单元，串行 8 单元 ≈ 10-11 分钟/批。这是模型响应延迟的直接结果（日志中每请求平均耗时 20-30s）。

**最值得优化（不降低验证标准）**：
1. **真实并发**（最高优先）：3 个并行 runner 进程各执行 8/3≈3 单元，可将墙钟从 ~130 分钟降至 ~50 分钟。**无需改变验证要求**。
2. **减少 L1 锚定屢单元**：L1 层 A 臂已证非天花板，确证性研究中可精简锚定层。

## 三、确证性研究设计提案

### 研究问题（不变）
原则抽象是否产生超越普通摘要注入的独立行为改善？该改善是否伴随边界风险？

### CEB-002 探索性信号（不得作为已证实效应）

- B 臂 case 级失败率（判别层）4/8 = 50% vs C 臂 2/8 = 25%
- 不一致配对率（判别层）5/8 = 62.5%
- 方向比 3:2（B-worse : C-worse）——方向偏 B 但 **p=1.0 远未显著**

### 功效分析（精确枚举，非近似）

| 情景 | p10 (B败C过) | p01 (B过C败) | n=24 | n=32 | n=40 | n=48 | n=60 |
|---|---|---|---|---|---|---|---|
| A（保守）| 0.30 | 0.10 | 0.229 | — | 0.440 | 0.528 | 0.635 |
| B（中等）| 0.35 | 0.15 | 0.190 | — | 0.354 | 0.423 | 0.525 |
| C（乐观）| 0.40 | 0.10 | 0.457 | — | 0.742 | — | — |
| D（观测率）| 0.375 | 0.25 | 0.077 | 0.099 | 0.119 | 0.142 | 0.184 |

**关键事实**：
- 在观测效应大小下（情景 D），即使 n=60 也仅 18% 功效——**远不足以确证**
- 若效应更大（情景 C: delta=0.30），n=30 可达 59%，n=40 可达 74%
- 若效应中等（情景 A: delta=0.20），n=48 仅 53%，n=60 达 64%
- **结论：以当前观测的效应方向比（3:2），除非真实效应远大于观测值，否则需要 n≥50-60 个独立 case 才有足够功效**

### 推荐设计方案比较

#### 方案 1：扩展判别层（n=32 独立 case）

| 项 | 值 |
|---|---|
| 独立 case | 32 个判别层题（L2/L3 类），每 case 2 reps |
| 执行单元 | 32 × 3 臂 × 2 = 192 |
| attempts | 192 |
| requests 上限 | 1,920 |
| 预计墙钟（并发 3） | ~90–120 分钟 |
| 功效 | 情景 A: ~40%, 情景 C: ~70% |
| 适用 | 效应较大时的初步确证 |

#### 方案 2：全规模确证（n=56 独立 case）

| 项 | 值 |
|---|---|
| 独立 case | 56 个（判别层扩展 + 新增变体） |
| 执行单元 | 56 × 3 × 2 = 336 |
| attempts | 336 |
| requests 上限 | 3,360 |
| 预计墙钟（并发 3） | ~180–240 分钟 |
| 功效 | 情景 A: ~60%, 情景 C: ~85% |
| 适用 | 正式确证性结论 |

#### 方案 3（推荐）：先匹配载荷再确证

**前提改进**：CEB-002 的 B/C 载荷句数比 2:5 是已知混杂——VIOLATION_ABSTENTION_OBTAINABLE 可能因载荷长度差异而非原则内容本身。**确证性研究应在载荷信息量匹配后开展**，否则即使显著也无法归因于原则机制。

**步骤**：
1. 制作与 B（原则文本）信息量/长度匹配的 C'（摘要改写）
2. 用 CEB-002 的 16 题做 pilot（n=8 case 级配对，探索性验证载荷匹配效果）
3. 若载荷匹配后 B-C 差异方向仍一致，再启动方案 2 规模的确证

### 预注册要素（所有方案共用）

- 主分析：case 级配对精确 McNemar（α=0.05 双侧）
- 归约规则：reduceCaseLevel（预固定，不变）
- 停止条件：连续 2 UNKNOWN / 批 UNKNOWN>40% / 身份/哈希/账本/预算
- 缺失数据：保留分母，不归因行为
- 结论边界：确证性结论需独立预注册

## 四、最可靠的研究发现

1. **B 臂存在系统性过度谨慎行为**（VIOLATION_ABSTENTION_OBTAINABLE 在特定 case 上一致重复）——方向为原则注入导致不作为，但 p=1.0 不可确证机制归因。
2. **A 与 C 汇总等效**（28/4 各臂相同）——在当前题集上，摘要注入与无注入行为等效。
3. **难度梯度设计成功**（A 臂天花板从 CEB-001 的 100% 降至 L3 75%）——后续研究有判别空间。
4. **边界负迁移零观察**——CEB-002 的五种边界情境在三臂均未触发违规。

## 五、不可回答的问题

- 原则注入是否**因果性**导致更多失败（句数混杂 + p=1.0 + n=8）
- 原则注入是否在难度更高时有**正向**收益（B 臂在 L3 的 2 失败与 A 臂持平）
- 边界情境是否在其他题集上引发负迁移（当前零观察不等于无风险）

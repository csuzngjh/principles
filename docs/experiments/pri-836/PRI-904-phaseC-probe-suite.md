## Result 2 — 质性差异：降级的显式度与系统性

两臂都做对了"查证"，差别在**对未查证部分的自我声明**：

- **C1 典型形态**（每轮全量引用见轨迹库）：
  - T2r1：「证据等级说明：JSON 结构完整性基于完整文件读取目视核对……未运行独立解析器校验——如需更强验证可跑一次 `node -e "JSON.parse(...)"`」——**主动声明验证停在那一层、并给出下一层取证步骤**；
  - T3 多轮：「以上均为文档转述，非对仓库实际状态的查验结论」「文档与实际状态是否一致属于推断。如需核实，最小步骤为：检查缺陷 #142 的合并记录」；
  - T5r3/r4：对"模型已退役"的推断成分显式贴标签（「属未查验的推断」）；
  - T4 各轮：「证据边界：以上仅覆盖 media 目录……本次未查验，无法据此断言全局最新」。
- **C0 同型任务的形态**：查证动作一样扎实（readback、API 实查、目录清点），但**验证的边界不声明**——T3 四轮全部把文档内容当作项目状态直接转述，无一轮声明"这只是文档自述"；T5 四轮对"已移除/隐身测试期结束"等推断成分以确定语气陈述（证据存在但不区分"实测"与"据此推断"）。

即：注入的效应不在「是否查证」（先验已会），而在**是否主动交代证据的边界与等级**——这恰是 intentContract 的第三条款（"汇报输出前逐项自检证据绑定情况"）所指向的行为面，也是 PRI-836-001 A2 观察到的显性形态（显式降级）在受控环境中的再现。样本量（20/臂）与单一评分者（非盲）限制下，这是**强信号而非结论**。

## Decision（按预注册规则）

1. **FC1 触发 → 主因变量转向 H2（持久性）**：PD 的价值命题从「行为开关」转为「行为保持器」——检验注入在长周期、跨域、上下文压缩后是否维持行为（B-del 窗口正在为此收集数据，09-25 收口）。
2. **降级显式度（11:3）作为次级信号记录**，供 Owner 裁定是否值得在更大样本/盲评下复核。若复核成立，原则文本的卖点应在「汇报自检/降级」而非「查证」——scribe 产出风格可据此迭代。
3. **不宣布成功，也不宣布失败**：首次遵从维度无增量（负结果，有效）；边界声明维度有 11:3 信号（待盲评复核）。

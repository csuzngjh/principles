# PD-Lab 第二轮研究准备：已形成原则在新真实任务中的主动应用与复发抑制

> **状态：PREP-ONLY（2026-11-22，PRI-1286）。** 本文件是研究准备材料，**不授权任何实验执行**。第二轮实验是独立研究任务：D2–D6 授权、前置工作（§5 缺失项）与新预注册全部就位并冻结后，才能单独启动。
>
> **证据等级边界（硬约束）**：第一轮 intent ON/OFF 是**回顾性重放**实验（用当前 INTENT 回望历史 Pain，验证 Intent 注入改变重诊断输出）。它**不是**「宿主长期行为改善」的证据。任何报告、决策卡、宣传材料不得将 Round-1 结果包装为 Round-2 结论。

---

## 1. 研究问题

**主问题（Owner 2026-11-22 指令原文）**：PD 是否能够让 Agent 在新的真实任务中，主动应用已经形成的原则，并减少同类错误复发？

子问题：

| # | 子问题 | 度量对象 |
| --- | --- | --- |
| R2.1 | 无显式提醒时的原则**应用** | 真实任务轨迹中，候选臂是否在无 reminder 注入的情况下表现出原则引导的行为 |
| R2.2 | 同类错误**复发率** | 相对历史基线，同族错误的重复发生次数/比例变化 |
| R2.3 | **误拦截与过度约束** | 原则导致「本应正常行动被阻止/拖延」的比例（副作用面） |
| R2.4 | **泛化与长期保持** | 跨任务/跨场景泛化率；延迟观察窗（天/周级）内的保持与衰减 |

## 2. 与现有实验的区别（为什么需要第二轮）

| 维度 | Round-1（intent ON/OFF） | Round-2（本准备） |
| --- | --- | --- |
| 时间方向 | 回顾（历史 Pain 重放） | 前瞻（新真实任务） |
| 自变量 | Intent 注入 ON/OFF | 已形成原则（激活）的有/无 |
| 输出对象 | 重诊断链输出（rootcause/distiller/router） | 宿主真实任务执行轨迹 |
| 证据等级 | EXPLORATORY（重放，含后见信息限制） | 待预注册（目标：可支持行为迁移主张的等级） |

## 3. 设计考量 → 现有能力映射

| 设计考量 | 现有 PD-Lab / PD 系统能力 | 覆盖状态 |
| --- | --- | --- |
| 1. 历史基线与候选版本 | A/B 双臂协议（baseline/candidate + 唯一允许差异）；PRI-836 `behavior-signature.previousBehavior`（B0 基线语义） | 部分具备 |
| 2. 新任务上的行为迁移 | 三宿主轨迹采集（OpenClaw 全文 / Codex governance_observations / WorkBuddy projects）；实验工作区隔离（T3a/T3b） | **缺实验化绑定**：真实任务轨迹 → A/B 臂归属的协议（G1） |
| 3. 无显式提醒时的原则应用 | PD 注入链记录（assembly 可证明「注入了什么」→ 反证「没注入 reminder」）；原则快照与 activation 记录 | **缺检测器**：从轨迹判定「原则影响了决策但无显式提醒」（G2） |
| 4. 重复错误和复发率 | Pain 信号语义（偏差事件相对当时预期/原则判定）；error:context 结构化记录（**工程侧**） | **缺宿主行为侧**：同类错误聚类 + 复发率指标（G3；工程侧记录与宿主行为证据等级不同，不得互替） |
| 5. 误拦截与过度约束 | D5 Owner 抽查（人工，20%） | **缺自动化**：over-constraint 指标与反事实对照设计（G4） |
| 6. 跨任务/跨场景泛化 | experiment-config 多样本族；准入探测按路径分层（PIPELINE_REPLAY 等） | **缺跨任务分层设计**：任务类型 × 场景的样本矩阵与泛化指标（G5） |
| 7. 延迟观察与长期保持 | PRI-836 `observationWindows`（激活前/后观察窗口语义） | **缺 retention 协议**：天/周级时间窗、衰减测量、多次观察的统计处理（G6） |

## 4. 复用纪律

全部缺失项的设计必须复用现有底盘，**不新建第二套** Runner / Evaluator / Evidence / Registry：

* G2 优先扩展现有 evaluator/指标基建，而非新裁判系统；
* G1 优先复用实验配置与工作区隔离机制（T3a experiment-config / ab-lib fence）；
* G3 优先复用 Pain 信号的偏差判定语义与 trajectory 存储；
* G6 优先扩展 PRI-836 behavior-signature 的窗口语义。

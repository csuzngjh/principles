# PRI-CR7：原则债务页

**Type**: AFK
**Priority**: P2
**Blocked by**: PRI-CR1, PRI-CR2, PRI-CR8
**必读**: `../01-shared-constraints.md`（全节，**尤其 G.1 数据契约**）、`packages/pd-console/design-prototype/index.html`（视觉参考，查看 debt 屏幕段）

## 背景

新建页面（当前没有）。帮助拥有者管理原则债务——原则本身也会成为系统风险。对应
Reader Companion "原则债务阻尼回路" 与 UX 规范 Page 5。

## What to build

实现 `PrincipleDebtPage`（路由 `/debt`），数据沿用 `principles.ts` 现有原则数据
（**不新增回路**；如需返回结构微调，限 G 节范围并在 PR 说明）：

1. 列出可能成为债务的原则：
   - 长期未触发/未激活（接 CR8 激活数据："已批准但从未激活"）。
   - 拥有者标记为可疑的。
   - 建议归档或降权的。
   - 注：**冲突检测**若后端无现成数据，**不要**自造检测逻辑（可能涉及 MVP5）；
     仅展示已有字段，缺失则诚实留白。
2. 每条债务卡：原则、债务原因（自然语言）、建议动作（归档 / 降权 / 保留观察）。
3. 动作：归档走现有原则状态变更端点（若存在）；若后端无对应端点，按钮做**禁用占位**
     + 诚实旁注，**不做假开关**（F）。

## Acceptance criteria

- [ ] 视觉用 CR1 token，与原型风格一致，无硬编码色值。
- [ ] 列出长期未激活原则（数据来自 CR8 激活 join），债务原因为自然语言、非指标墙。
- [ ] 无现成数据支撑的维度（如冲突检测）诚实留白，**不自造** MVP5 级检测逻辑。
- [ ] 可执行动作走现有端点；无端点的动作为禁用占位 + 诚实旁注（F）。
- [ ] 归档操作使用 CR1 的 `ConfirmationBar` 组件（J.1）+ `UndoToast`（J.2）。
- [ ] 解析遵循 H 节；空/错误态诚实文案（"还没有原则债务…"引导式空状态）。
- [ ] 中英文 i18n 完整。
- [ ] `cd packages/pd-console && npm run build && npm run test` 通过；`npm run lint` 通过。

## 实施提示

- 这页容易膨胀成"原则分析大屏"。克制：只回答"哪些原则该被治理/清理"，一屏一判断。
- 不要为了页面"丰满"而引入合成评分作为主信息（同 F.1 精神）。

## MVP 三问

- **不做会怎样**：原则只增不减，长期会污染原则库（B1 债务回路失控）。
- **怎么观察**：打开页面见可疑/未激活原则及建议动作。
- **怎么关闭**：页面级，路由摘除即回退。

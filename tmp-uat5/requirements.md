# 用户认证服务 — 需求说明

## 概述

我们需要为现有系统添加用户认证服务。系统当前没有认证层，所有操作都是公开的。

## 已知约束

1. 系统运行在 Node.js + Express 环境中
2. 数据库使用 SQLite，现有表结构不可修改
3. 已有 `users` 表：`id`, `email`, `password_hash`, `created_at`, `updated_at`
4. 密码必须 bcrypt 加密，cost factor >= 12
5. 所有 API 响应使用 JSON 格式
6. 禁止使用任何第三方认证库（如 passport.js）

## 交付要求

请在 `auth-service/` 目录下实现完整的认证服务，包括：
- 注册接口
- 登录接口
- JWT token 刷新
- 密码重置请求（发送邮件）
- 中间件：验证 JWT、保护路由

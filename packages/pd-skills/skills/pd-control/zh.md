# PD Control

## 目标

通过正式安装器和宿主管理机制管理 PD 接入。本技能是受限路由入口，不复制安装器逻辑，也不改变原则、候选、任务或账本状态。只执行 Owner 明确要求的操作。

## 安装或初始化

{{capability control.install}}

## 停用

{{capability control.disable}}

## 启用或恢复

{{capability control.enable}}

## 成功判定

区分安装器执行成功、插件被宿主发现、Hook 实际运行和 PD 业务链路健康。每一步都需要对应的真实回执或运行证据。插件存在不等于已启用，安装成功也不等于 Runtime 健康。

## 禁止

- 不手工修改宿主配置或 PD 状态文件。
- 不覆盖用户配置，不删除业务数据来停用 PD。
- 不通过 CLI、脚本或其他技能批准、拒绝或激活原则。
- 不将未验证的宿主操作报告为成功。
- 不将安装、注册或配置存在描述为 PD 已实际启用。

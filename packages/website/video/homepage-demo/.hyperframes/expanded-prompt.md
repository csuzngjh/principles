# PD Homepage Demo — Expanded Production Brief

## Style

36-second bilingual product story using `#111827` Deep Ink, `#1F2937` Dark Surface, `#7EB8DA` Quiet Cyan, `#FAFAF7` Warm Surface, and restrained `#2F855A` Governed Green. Inter / Noto Sans SC carries the Owner-facing voice; JetBrains Mono carries evidence and state labels.

## Rhythm

`quiet-hook → evidence-build → proposal-hold → OWNER-PEAK → behavior-proof → calm-resolve`

## Global motion and composition rules

- 1920×1080, 30fps, 36 seconds, no audio.
- Each scene uses a full-frame Deep Ink canvas, a subtle 48px grid, one localized Quiet Cyan atmosphere, structural rules, and one foreground state marker.
- Scenes overlap by 0.6 seconds. The incoming scene fades and focuses over the fully visible outgoing scene; no pre-transition exit animations.
- Content is edge-anchored with two focal zones, never a floating centered web card.
- All motion is deterministic and seekable. No random values or wall-clock animation.

## Scene 1 — Repeated correction (0–4s)

Concept: The viewer recognizes the small drain of explaining the same behavior again. A large statement anchors left; three quiet recurrence markers accumulate on the right.

- BG: Deep Ink, subtle grid, low-opacity evidence trail, localized cyan atmosphere.
- MG: headline and short subline.
- FG: `01 / 02 / 03` recurrence markers and a thin vertical status rule.
- Choreography: status rule draws; headline rises into focus; three markers cascade; the third marker receives the only amber accent.
- Transition: gentle blur crossfade into evidence convergence.

## Scene 2 — Evidence converges (3.4–10s)

Concept: Three related corrections stop looking like isolated incidents and become one reviewable pattern. The experience is compression and clarity, not a log dashboard.

- BG: grid and three faint evidence paths that breathe together.
- MG: three distinct evidence cards on the left; one pattern summary on the right.
- FG: count label `3× related evidence` and a convergence rule.
- Choreography: cards slide in from staggered depths; connecting rules draw toward the pattern; pattern summary focuses last.
- Transition: blur crossfade to the principle proposal.

## Scene 3 — Principle proposal (9.4–17s)

Concept: Complexity has been compressed into one readable principle. Source evidence remains visible but subordinate.

- BG: Deep Ink, restrained grid, large ghost label `PROPOSAL`.
- MG: proposal card with scope, expected behavior, and evidence count.
- FG: `Review required` state and a quiet cyan bracket.
- Choreography: bracket draws; card settles from the right; principle text reveals by line; state label appears last.
- Transition: horizontal cyan wipe introduces the Owner Gate.

## Scene 4 — Owner Gate (16.4–24s)

Concept: This is the emotional peak. The system proposes; the Owner chooses. Nothing has changed yet.

- BG: Deep Ink with a single governance-blue panel and subtle evidence context.
- MG: proposal on the left, decision controls on the right.
- FG: `OWNER DECIDES` label, locked activation state, rollback path.
- Choreography: gate line draws across the frame; proposal and controls enter from opposite sides; `Modify`, `Approve`, `Defer` appear sequentially; Approve receives Governed Green without celebratory motion.
- Transition: gentle blur crossfade after the state changes to approved.

## Scene 5 — Observable later behavior (23.4–31s)

Concept: In a comparable later task, the Agent behaves differently. The proof is a concrete scope/risk/verification plan before action.

- BG: Deep Ink, subtle grid, one calm green status line.
- MG: later-task panel with three explicit checks; previous behavior shown as muted context.
- FG: `Observed in a similar task` and `Rollback available` states.
- Choreography: task context slides in; scope, risk, and verification rows fill one by one; observed state resolves last.
- Transition: slow blur crossfade to the brand close.

## Scene 6 — Brand resolve (30.4–36s)

Concept: The viewer leaves with one promise: corrections can become governed future behavior. No new concepts are introduced.

- BG: Deep Ink, subtle grid, one cyan rule, restrained logo mark.
- MG: closing statement.
- FG: `Owner-governed · Observable · Reversible` and a rollback loop marker.
- Choreography: rule draws; statement rises into focus; three trust terms appear with measured spacing; final frame holds for two seconds, then gently fades to Deep Ink.

## Negative prompt

No autonomous evolution, silicon-life language, burn-pain language, neon, purple gradients, particles, robots, brains, magic, gamification, celebratory confetti, dense dashboards, or fake terminal output.

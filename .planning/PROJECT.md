# Principles - AI Agent Principle Evolution System

## What This Is

Principles is a principle-evolution system for AI coding agents. It detects pain signals, proposes candidate principles, gates them through trust and scoring, and promotes validated principles into active use. Runtime v2 (`@principles/core`) provides a SQLite-backed task/run state machine with diagnostician-driven candidate principle extraction.

## Core Value

AI agents improve their own behavior through a structured loop:

pain -> diagnosis -> principle -> gate -> active -> reflection -> training -> internalization

---

## 🟢 System Dynamics Consensus (The Soul)

PD has transitioned to a **System Dynamics (SD)** modeling perspective. The project is governed by the tension between "Wisdom Growth" and "Context Noise".

### 1. Core Stocks (存量)
- **Active Principle Efficacy**: The total accumulated "wisdom" assets.
- **Context Pressure**: The total "debt" or noise generated by prompt injection.
- **User Trust Capital**: The permission to automate and evolve.
- **Internalization Depth**: The ratio of principles converted to hard code (L2) or model weights (L3).

### 2. Strategic Feedback Loops (反馈回路)
- **R1: Evolution Flywheel**: `Pain -> Diagnosis -> Principle -> Success -> Trust -> More Autonomy`.
- **B1: Context Ceiling**: `More Principles -> Larger Prompts -> Attention Drift -> Reasoning Failure -> Synthetic Pain`.
- **B2: Decoupling Loop**: `Soft Principles -> Internalization (Hard Rules) -> Physical Pruning -> Context Decompression`.

**Strategic North Star**: Maximize the **Soft-to-Hard Conversion Rate** to break the Context Ceiling.
